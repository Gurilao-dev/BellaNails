# 💅 Bella Nails – Studio de Unhas & Gestão para Manicures

Sistema moderno e completo para manicures, nail designers e salões de beleza gerenciarem seus negócios com excelência e aumentarem seus lucros.

---

## ✨ Funcionalidades Principais

- 📅 **Agenda Inteligente:**
  - Visualização de horários diários e semanais.
  - Bloqueio e liberação de horários com cálculo de tempo de procedimento.
  - Lista de agendamentos com status e valor por atendimento.

- 👥 **Gestão de Clientes:**
  - Cadastro detalhado de clientes com histórico de visitas e preferências.
  - Acesso rápido a contatos e serviços frequentes.

- 💅 **Catálogo de Serviços:**
  - Cadastro de serviços (Alongamento em gel, Banho de gel, Manicure, Pedicure, Nail art).
  - Configuração de tempo de duração e valores.
  - Upload de fotos personalizadas pela câmera/galeria ou seleção entre fotos padrão de modelos de unhas.

- 💰 **Painel Financeiro Completo:**
  - **Resumo Financeiro:** Faturamento do mês, métricas de crescimento e gráfico interativo de desempenho semanal.
  - **Entradas:** Registro individual de cada atendimento realizado com método de pagamento (Pix, Cartão de Crédito/Débito, Dinheiro) e data.
  - **Despesas & Produtos:** Controle de custos mensais fixos (aluguel de mesa, internet, luz, MEI) e custos variáveis, com catálogo de produtos e compras em 1 clique.
  - 🎯 **Calculadora de Ponto de Equilíbrio (Break-Even):**
    - Quantidade exata de unhas necessárias para cobrir 100% dos custos do estúdio.
    - Metas de ritmo por dia útil e por semana.
    - Termômetro em tempo real do mês atual.
    - Margem de contribuição líquida por atendimento.
    - **Simulador de Salário dos Sonhos:** Projeção de atendimentos para a meta de renda limpa.
    - **Simulador de Reajuste:** Análise do impacto de aumento de preços no faturamento e tempo trabalhado.
    - **Matriz de Capacidade Diária:** Projeções de lucro de 1 a 4 clientes por dia.

## 🚀 Como Executar Localmente

1. Clone o repositório:
   ```bash
   git clone https://github.com/Gurilao-dev/BellaNails.git
   ```

2. Instale as dependências:
   ```bash
   npm install
   ```

3. Inicie o servidor de desenvolvimento:
   ```bash
   npm run dev
   ```

4. Abra no navegador:
   ```
   http://localhost:5173/
   ```
